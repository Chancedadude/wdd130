Client Report

Client: The content and images that I used to create the website were ideas I mostly came up with. The images were made from Chatgpt and the content was something I wanted to have the lead developer and junior developers add to the website. I communicated my developers through email. There weren't any problems other than not hearing from one of my junior developers. Other than that it went smoothly. Yes the developer met my expectations for the website. Something i will do differently for next time is communicating with my team more often. It will help make the project more efficient and communication is key to creating a good website.

Video Game Website

Lead developer Report: I managed my development team by communicating and help answer some questions that they may have about the repository and website. I communicated with my client by attending in person meetings to go over the progress on the webpage. No there wan't any issues. I published the clients site using their prefeered hosting platform. I made sure that everything was full functional and then shared the live link along with the code that was used to create the webpage. Github was completely new to me, which made me feel lost about some of the settings and how to create the repository. Other than that it went okay.

Soccer Website

Unfortunately I couldn't do much because of lack of communication. Yes I ran into a lot of issues but it wasn't with Github and adding the changes. It was mostly not having the things I needed to start working on the childpages.

Recipes Website

General Experience and Reflections: The most challenging part of the project was communication. I did my best to overcome this issue, but it was a permanent error. i enjoyed making the homepage for my client and communicationg with my team. Something I would do differently if I had to do the project again is making sure that everyone is communicating. There wasn't much communication throughout the project and it would be good to have more of that. I feel more confident about working on real-world projects, but not entirely. I need to learn how to communicate better and if i can get that to work, then i would feel a lot more confident working on projects like this.
